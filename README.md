# Personal Statement on Ethics
I value responsibility and honesty in not only my actions through technology but in all of my actions.
These values matter to me because the choices I make can impact others around me especially in a learning community.
It is ethically impermissible to act carelessly, decieve others, or ignore how my actions affect those around me.
I strive to uphold these values by being accountable for my work, supporting my peers, and reflecting on the consequences of my decisions in both academic and everyday settings.
